# 動画の置き場所

このフォルダに **`intro.mp4`** という名前で動画を置くと、
トップページのヒーロー部分に自動で表示されます。

置いていない間は「動画準備中」のプレースホルダーが出るだけなので、
サイトが崩れることはありません。

## 撮影メモ

- **向き**：横向き（16:9）
- **長さ**：15〜25秒程度
- **台本**（丸暗記せず、自分の言葉で話す）

> 愛知県に住んでいる、小澤昊真です。
> 武蔵野大学アントレプレナーシップ学部を志望しています。
> 実際にやってきたことをA4一枚だけでは伝えきれなかったので、自分でこのサイトを作りました。
> よければ見てください。

## ファイルサイズについて

スマホで読み込まれる前提なので、**10MB以内**を目安に書き出すこと。
長すぎる・重すぎる場合は解像度を1080pか720pに落とす。
