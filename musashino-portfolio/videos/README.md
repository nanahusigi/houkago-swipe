サイトが崩れることはありません。

## 撮影の指定

| 項目 | 指定 |
|---|---|
| 向き | **横向き（16:9）** |
| 画角 | バストアップ（胸から上） |
| カメラ位置 | **自分の目の高さ**。1〜1.5m離れる |
| 目線 | レンズを見る（画面の自分を見ない） |
| ヘッドルーム | 頭の上に指2本分の余白 |
| 長さ | 15〜25秒 |
| 解像度 | 1080p |
| ファイル | `intro.mp4` / 10MB以内 |

### 背景

- **作業机まわりを写す**（本棚・PC・作った物）。「日常的に作っている人」という文脈が無言で伝わる
- 壁から1mほど離れて座る（奥行きが出る）
- NG：ベッド、散らかった服、暗い部屋、窓を背にした逆光

### 光

- **窓に向かって座る**。昼間（14〜16時が安定）
- 夜に撮るなら、デスクライトを顔の斜め前45度から。壁や白い紙に当てて反射させる

### 音（映像より重要）

- エアコン・扇風機を止める
- 内蔵マイクなら口から50〜70cm
- 音が悪い動画は最後まで見てもらえない

## 撮り方の手順

1. 台本を声に出して2回読む（丸暗記はしない）
2. 録画スタート → **2秒待ってから**話し始める
3. 話し終わったら **2秒静止してから**停止（編集の余白）
4. 3〜5テイク撮る。1テイク目は硬くなるので捨てる前提
5. 一番自然だったものを `intro.mp4` にリネームしてこのフォルダへ
6. `git add` → `commit` → `push` でサイトに反映

## 話し方

- 緊張すると早口になる。**普段の8割の速度**を意識する
- 真顔で始めて、名前を言い終わったあたりで少し緩むくらいでちょうどいい
- 「えー」「あの」が1回入るのは、むしろ自然で誠実に見える。消そうとしない
- 暗記した文章の棒読みが一番よくない。意味を分かって喋る
