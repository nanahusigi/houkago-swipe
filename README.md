# 放課後スワイプ

岡崎の高校生が、放課後に誰かと飯へ行くまでの「言い出す役」を引き受けるアプリのコンセプトデモ。

## リンク

- **デモ** … `index.html`
- **決まったことの全記録** … `docs.html`

GitHub Pages を有効にすると、以下で公開されます。

```
https://<ユーザー名>.github.io/houkago-swipe/
https://<ユーザー名>.github.io/houkago-swipe/docs.html
```

## デモでできること

**今日、外で食う？（毎日のループ）**

1. 通知「今日、外で食う？」
2. 昼 / 放課後 / 夜 を1タップ（押さない＝表明なし）
3. 合う友達がいたら両方に同時通知。いなければ人数だけ匿名表示
4. 今日の3枚（＋広告1枚）をスワイプ
5. 今日の1軒が必ず出る

**はじめて（好みを登録）** … まとめてスワイプして好みを取る

**みんなで決める** … 4桁コードで部屋を立て、その場の3人で同時にスワイプ。多数決で必ず1軒

カードを**タップ**すると詳細が開き、写真が複数枚見られます。チェーン店は代表1枚のみ。

## 注意

デモ用のダミーです。**店名・学校名・数値はすべて架空**で、実在の店舗や学校とは関係ありません。

## 構成

単一HTMLファイル。外部依存なし、ビルド不要。ブラウザで開けば動きます。
